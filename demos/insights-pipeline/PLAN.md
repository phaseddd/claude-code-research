# insights-pipeline · Demo 设计规划 v3

> 交互演示：Claude Code `/insights` 从输入命令到写出 HTML 报告的流水线。
> 形态：3D 科普叙事体验（借鉴 why.zero.university 的"帅"，不借其皮）。
>
> 状态：v3 规划（主人确认分镜决策后），实现待启动。

---

## 0. 设计总纲

1. **观众是第一次来**：打开页面的人不知道 /insights、不知道知识库。叙事要自己建立背景。
2. **要帅，不抄分镜**：借零大学的"质感"（3D 沉浸、节奏交错、进度可感、情绪化色彩、数据即场景物体），叙事结构完全独立：**黑盒揭晓**。
3. **措辞不虚构**：所有流程、数字、机制锚定两篇知识页。cap 约值用"约/上限"措辞；推测用"合理推测"措辞。演示数据标注"合成示例"。
4. **文案政策**（主人 2026-07-31 确认）：
   - 信息量**不设限**：科普向，每站可放开写，排版分层（大字核心句给方向 + 小字展开段给细节）
   - 语气：科普第一，可适度加入猫娘式俏皮（HUD 提示、引导语、彩蛋句），主体科普段落保持专业
   - 术语首现给大白话，中文为主、术语保留原文

**叙事弧：黑盒揭晓（三幕）**

```
序章 · 你的视角    你按下回车 → "analyzing your sessions" → 等待 → 收到链接
  │                      ↑ 黑盒悬念："那段时间里到底发生了什么？"
  ▼
第一幕 · 数据      引擎认识你的历史：分发 → 扫盘 → 缓存（快、奇观）
  ▼
第二幕 · 理解      对话被压缩、被读懂：投影 → 打标签（慢、重场戏）
  ▼
第三幕 · 生成      报告长出来：七章并行 → 总览 → 落盘交付（仪式高潮）
  ▼
尾声 · 回到你的屏幕   那两行英文 + file:// 链接再次出现 —— 但你现在懂了
```

## 1. 参考解剖：why.zero.university（素材库）

### 1.1 技术栈（chrome-devtools 实测验证）

Vite 单 bundle · 原生 Three.js（WebGL2 超采样 2560×1275 + 大量自定义 shader）· GSAP · Howler · 自研 lerp 平滑滚动（wheel 完全接管）· 自定义光标图集。

### 1.2 机制层（bundle 静态分析 + 合成输入逐阶段验证）

| 机制 | 验证证据 |
|---|---|
| 多阶段时间轴：每段独立滚动预算 scrollVh + gate 自动滚动过渡段 | segments：stage1 175vh → gate 50vh(autoScroll) → stage2 250vh → … |
| 滚动接管：wheel deltaY×35 → targetScrollPos → rAF lerp，body overflow hidden | `_onWheel` 源码 |
| TAP HOLD：按住按钮，SVG 进度环填充，时长达标触发 | `Tg` 类源码 + 实按验证（XP 300→400） |
| 画圆手势：≥330° 且圆度误差 <35% 且闭合 | `_checkZeroGesture` + 实画验证 |
| XP 计量：每推进 +100，数字滚动动画 | 全程采样 100→500 |
| HUD：XP / 任务状态 / 标尺导航 / SCROLL 指示 / 音频开关 | DOM 全程 |
| 终局：证书相框 + 公司卡片视频 + Join Beta 表单 | `frame-open`、`origami_certificate.webp` |

### 1.3 质感层（十张截图拆解 + 主人确认吸收）

零大学真正的帅不在机制而在**叙事设计**，拆解如下（grok 识图反馈 + 代码层验证交叉）：

1. **叙事短片结构**：十屏 = 十个情绪节拍（相信→承诺→触碰→崩坏→怒骂→数据→金钱→燃烧→真相→抉择），每屏只服务一个节拍，信息密度克制
2. **一个贯穿的 3D 隐喻主体**：全场是"一只手"—— 概念可视化，不为炫技堆模型
3. **色彩即情节**：白/薄荷绿（希望）→ 红（幻灭）→ 暗绿黑（真相），场景复用 + 调色反转制造冲击
4. **数据不做列表，做成场景物体**：玻璃碎片=统计卡片、飞舞纸片=名人语录，信息本身成为场景美术
5. **字即图形**：超大 display 字 + 小 caption，大负空间，字与 3D 主体咬合
6. **统一交互语言**：TAP HOLD 贯穿全场，交互即剧情
7. **固定 HUD 不抢戏**：XP、Join Beta、SOTD 常驻，建立产品感
8. **情绪优先于功能说明**：先让人"感受到"，再给数据

**我们吸收为：三幕情绪节奏 + 光河贯穿主体 + 重场戏独立奇观 + 数据即物体 + 字阶排版。**

**文案草案**（信息量放开，排版分层）：

```
（展示字体大字）
/insights：回车之后，发生了什么？

（正文展开段）
```

### 2.2 主体 · 引擎的八站（三幕）

**贯穿主体：光河** —— 一条发光的数据河 = 你的历史会话。河流宽度 = 信息量。全程跟随同一条河被逐层加工；重场戏站（S4/S5/S6）河流展开为独立大奇观。

**推进节奏**：站内滚动探索（光河流动）↔ 站间 TAP HOLD 推进（引擎运转仪式）↔ gate 自动过渡（镜头转场）。统一交互语言：**滚动=看，按住=走**。

**TAP HOLD 全剧仅 3 次（仪式时刻）**：
1. 序章 —— 按住"运行 /insights"（观众按下回车）
2. S3→S4 —— 进入第二幕"模型介入"（按住 = 把数据交进模型手里）
3. S7→S8 —— 交付仪式（按住 = 落盘生成报告）

其余站间用滚动 + gate 自动过渡，避免重复疲劳（参照零大学 10 屏仅 3 处按住）。

#### 第一幕 · 数据（快节奏，奇观感：本地、确定、唰唰唰）

| 站 | 人话标题 | 3D 场景 | 文案要点（措辞草案） | 事实锚点 |
|---|---|---|---|---|
| S1 | 命令命中 | 终端风 UI：`/insights` 输入 → 命令表命中 → "analyzing your sessions" 浮现，光河源头点亮 | "`/insights` 是内置命令，不是模型现场想出来的。它命中命令表，屏幕上出现进度提示：'analyzing your sessions'。真正干活的是报告引擎；当前对话的模型只负责最后递链接 —— 两个角色，各司其职。" | 内置 builtin、progressMessage、双模型角色 |
| S2 | 扫盘 | 光河 = 会话星云：每颗星一个历史会话（JSONL 消息日志），新旧 mtime 亮度渐变；一颗暗淡的"元会话"星被弃置 | "引擎走进 ~/.claude/projects/，枚举你所有的历史会话 —— 一条条 JSONL 消息日志。目录为空就空跑退出；有货就按时间从新到旧排队。特殊会话会被丢掉：/insights 自己产生的元会话，不是你的对话。" | 枚举、空跑退出、JSONL、元会话丢弃 |
| S3 | 缓存分流 | 光河分流成两条：meta（青，纯计算）与 facet（品红，模型判定），流向缓存盒；mtime 未变的盒不发光（复用） | "几百个会话，每次都从头分析太慢。引擎有两层缓存：meta 是算得出来的统计 —— 时长、工具次数、token 消耗，文件没变就复用；facet 是模型才判断得了的语义标签 —— 目标、满意度、摩擦，每次抽取都花 token，所以保守。两层分开存，更新互不误伤。成本与确定性不同，待遇就不同。" | 两类缓存、成本/确定性、cap 措辞"有数量上限" |

#### 第二幕 · 理解（放慢，重场戏：压缩与语义，信息密度最高）

| 站 | 人话标题 | 3D 场景 | 文案要点（措辞草案） | 事实锚点 |
|---|---|---|---|---|
| S4 | 过滤与投影 | **重场戏展开**：光河变窄 —— 你的消息每条最多保留约 500 个字符、Claude 回复每条最多保留约 300 个字符、工具调用只留名字的标签在管道里飞；筛子丢弃 <2 条消息或 <1 分钟的会话；超 3 万字符的光河切片成 2.5 万字符一段，各产出一段 500 token 摘要 | "两条硬门槛：你至少发了 2 条消息，且对话至少 1 分钟 —— 太短的会话没有信息量。接下来是有损投影：你的消息每条最多保留约 500 个字符，Claude 的回复每条最多保留约 300 个字符，工具调用只留名字 —— 参数、diff、系统消息都丢掉。超过 3 万字符就切片摘要。压缩链每一环都在为后面保留关键细节：文件名、错误信息、你的反馈 —— 它们要用来写摩擦分析。" | 质量过滤、投影规则表、30000/25000/500、P1 保留细节 |
| S5 | 打标签 | **重场戏展开**：光河河水升起十个标签物体（underlying_goal / outcome / session_type…），悬停解释字段含义；warmup_minimal 标签的会话星暗淡退出统计 | "投影后的文本交给内部模型，输出一份结构化 JSON —— 十个字段，描述这个会话：根本目标、结果、满意度、摩擦类型……准则很严：只数你明确提出的请求，Claude 自己跑去探索代码库不算。太短的会话统一标 warmup_minimal —— 不进统计，避免拉偏整体。抽取失败的会话静默跳过，不影响整份报告。" | P2 准则、P3 Schema、warmup_minimal 剔除、校验失败静默跳过 |

#### 第三幕 · 生成（仪式高潮：并行爆发 → 汇聚 → 交付）

| 站 | 人话标题 | 3D 场景 | 文案要点（措辞草案） | 事实锚点 |
|---|---|---|---|---|
| S6 | 七章并行 | **重场戏展开**：光河汇聚成公共数据串，七条光线并行注入七个章节星球同时点亮（工作领域/交互风格/做得好的/摩擦/建议/前瞻/彩蛋），30 分钟重叠检测的波纹掠过 | "引擎把跨会话数字汇总：工具使用、语言分布、目标类别、满意与摩擦、是否在多个会话间并行（30 分钟窗口）。然后七章同时开写：工作领域、交互风格、做得好的地方、摩擦分析、改进建议、前瞻机会、结尾彩蛋。七次模型请求全部并行 —— 不是一章一章等。每章独立提示词模板，共享同一份数据。" | 聚合（30 分钟重叠）、七章并行 8192、章节名 |
| S7 | 总览合成 | 七束光汇聚旋转成核心：At a Glance 四段逐段浮现（What's working / hindering / Quick wins / Ambitious） | "七章全部返回后，再做一次调用，合成 At a Glance 四段：什么在起作用、什么在拖后腿、现在就能试的、面向更强模型的雄心。它是七章之上的再加工 —— 先看完所有章节，再决定呈现什么。教练语气，不堆数字 —— 数字留给 HTML 里的图表。" | P11 四段、后见之明、不堆数字 |
| S8 | 落盘交付 | 光河注入 report.html（折纸展开，0600 权限角标）→ 主会话话术注入 → 两行英文浮现 | "七章 JSON、总览 JSON、聚合统计一起喂给渲染函数，写出 report.html 和带时间戳的副本，权限 0600 —— 只有你能读。引擎把完整数据塞进主会话上下文，附一条强制话术：输出只能是 <message> 标签里那两行。于是聊天窗里出现那两行熟悉的英文。" | 写盘两文件、0600、P12、isMeta+shouldQuery |

### 2.3 尾声 · 回到你的屏幕

**呈现**：视角拉回"聊天窗"，两行英文原样展示，file:// 链接浮动；八站缩略图排开可点击回看（hover 显示该站要点）；"重新体验"按钮。

**文案草案**：

```
（等宽字体，聊天窗样式）
Your shareable insights report is ready:
file:///Users/you/.claude/usage-data/report.html

Want to dig into any section or try one of the suggestions?

（正文展开段）
这就是你按下回车后看到的一切。但你现在知道：链接背后是八个环节、
两类缓存、三处模型调用点的旅程 —— 你的历史从一条光河，
变成了这份报告。

报告内容为合成示例：本演示不读取真实会话数据，
只演示流水线本身的工作方式。

（俏皮小字，适度）
想深入了解哪一节？点击下方八站回看 —— 或者去知识库读完整解析，那里连提示词原文都有。
```

### 2.4 措辞规范

1. 术语首现给大白话：facet —— 模型给每个会话打的语义标签；有损投影 —— 把原始记录压成简明文本，细节有取舍
2. 中文为主，术语保留原文（`/insights`、facet、meta、JSONL、At a Glance、`<message>`）
3. 数字措辞诚实：投影截断"约 500/300 字符"；cap 值说"有数量上限"；精确值只来自知识页原文
4. 动机措辞分级：源码可证 → "引擎会…"；推测 → "合理推测"
5. 不虚构：不展示真实报告的完整内容（只有合成示例，且标注）；不展示引擎的"界面"（它是纯代码流程，没有界面）
6. 界面禁用 emoji 字符（U+1F000+ 码位，装饰/图标/语气词一律不用）；排版符号（→ ★ ※）不受限，俏皮靠文字实现

### 2.5 合成数据设计（知识库元叙事）

虚构 12~15 个会话，围绕本知识库工作流（intake 入库、机制分析、facet 自举、知识页打磨、零站点解剖等），手写 meta（时长/消息数/工具/语言）与 facet JSON（目标/满意度/摩擦/类型）。七章示例内容由这些会话自然引申，尾声明确标注"合成"。

## 3. 技术方案

```
Vite + 原生 Three.js + GSAP（无 React）
```

| 模块 | 方案 |
|---|---|
| 时间轴 | 自研 MasterTimeline：segments 自包含生命周期（`enter(ctx)` 异步构建 / `scrub(ctx, p)` 段内进度 0~1 / `update(ctx, t, dt)` 每帧 idle 动画 / `teardown(ctx)` 释放交接）+ `scrollVh` 虚拟滚动预算 + gate 自动过渡段 —— 形态对齐零大学官方工程文章（Codrops 2026-07-17），M1 实现此形状 |
| 滚动 | 自研 lerp 平滑滚动，body overflow hidden；站内滚动 = 看，站间按住 = 走 |
| 推进交互 | TAP HOLD（进度环）+ 站内滚动；无画圆手势。**按住只在仪式性时刻出现**（进入模型环节 / 交付），第一幕连续滚动 —— 避免机械重复（参照零大学 10 屏仅 3 处按住） |
| 光河 | 粒子流管线（自定义 shader：河宽 uniform、流速、颜色渐变），贯穿各站；重场戏站河流展开为独立装置 |
| 重场戏 | S4 压缩管道（粒子收缩+标签流）、S5 标签物体群（十个字段卡，hover 解释）、S6 七星球+光线 |
| HUD | 底部 8 节点流水线轨道 + 站标题 + 数字滚动反馈；序章/尾声为 2D DOM 排版 |
| 字体 | 主标题 `/insights` 命令图形：Playfair Display 900 斜体（西文 display，零大学衬线张力的对应物，OFL 免费、分包实测几十 KB）+ 中文副题思源宋体 Heavy 900（报告/档案感）/ 数据与终端 JetBrains Mono / 正文 Noto Sans SC 400/500 |
| 数据 | `src/data/sessions.js`（合成 meta/facet）+ `chapters.js`（七章合成示例） |
| 降级策略 | 无 WebGL2 时：序章（背景文案 + 八站要点 + 知识页链接）以静态页面呈现，科普信息不丢；WebGL 体验为增强层 |
| 性能预算 | 桌面 60fps 目标：粒子数控制在 1e4 量级、单 canvas 渲染、devicePixelRatio 上限 2（不做 3× 超采样，那是零站点的开销我们不需要） |
| 音效 | 可选 WebAudio 合成（M6 再定） |
| 色彩叙事 | 序章黑场 → 第一幕冷蓝（数据）→ 第二幕青紫（模型介入）→ 第三幕琥珀（报告成形）→ 尾声白场 |

## 4. 决策记录

| 决策 | 结论 |
|---|---|
| 合成数据叙事主题 | 知识库自身工作流（元叙事） |
| 分镜结构 | **八站三幕**：数据（快）→ 理解（慢）→ 生成（仪式） |
| 贯穿隐喻 | **混合**：光河作主线贯穿，重场戏站（S4/S5/S6）展开独立大奇观 |
| 交互语言 | 滚动=看，按住=走；**TAP HOLD 全剧仅 3 次**（序章 / 进入模型 / 交付）；无画圆 |
| 主标题字体 | `/insights` 命令图形化：Playfair Display 900 italic 超大斜体 + 中文副题思源宋体 Heavy 900。否决"花体贯穿"理由（2026-08-03 联网复核"中文无花体字库"判断后修正）：中文 display 系不缺免费可商用选项（思源宋体 Heavy / OFL 书法系，Google Fonts 分包单片 2.8~43KB 实测），真正理由是书法体可读性受限 + 数据/终端气质契合；帅感由西文命令字承担（零大学大字是 sprite 贴图渲染，我们走 DOM webfont 路线） |
| 图形语言 | **字即图形**：图形标记一律字符（青色 → 箭头）+ 几何 + 3D 物体，**不引入图标库**（否决 Lucide，2026-08-05 主人确认）—— 字阶体系已确立"字符 + 光晕"数据视觉语言，线性 UI 图标与艺术衬线气质异质 |
| 文案政策 | 信息量不设限；科普语气；适度猫娘俏皮；措辞不虚构 |
| gate 内滚动 | 用户 wheel 可加速、不可减速（autoScroll 下限钳制）—— 电影式转场不停车，滚过头需滚回上一段再进；M2 HUD 轨道导航提供直接跳转 |
| 视频混合 | v2 增强（M0~M6 纯 WebGL shader） |
| 里程碑 | M0~M7 按幕拆分（本表） |
