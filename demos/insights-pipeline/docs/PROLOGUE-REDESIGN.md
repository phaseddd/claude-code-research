## 0. 定位

`/insights` 是 Claude Code 内置命令：读你过去对话记录（叙事口径「这个月」），生成「你实际上是怎么用 Claude Code 的」HTML 报告——在哪卡壳、哪些模式有效、该改什么。**它是唯一会审视你的工具**——平时你命令它，今天轮到它点评你。

序章 3 秒只做一件事：让用户意识到「**这次是它在看我**」。意识到那一瞬，用户自己会按，不用推。

## 1. 时间轴（≈3 秒）

| 时间 | 节拍 | 内容 |
|---|---|---|
| 0 ~ 0.9s | **一次摆好** | 单段并行：标题 `/insights` 逐字锐化（单字符 0.35s，stagger 0.05s，**保持暗**）→ 副题+钩子合拍轻落 → 报告条目块整块落位（≤400ms，禁逐字弹入）→ 三环节淡入 → 圆环首帧可见 → 点题句暗态在场 |
| 0.9s | 悬置 | 首行条目 `▌` 光标开始闪烁（CSS animation，1s cycle）——「这条还没完，等你 Enter」 |
| 0.9 ~ 0.98s | 停顿 | 80ms 全场静（心跳星/圆环/颗粒停一拍） |
| 0.98s | **可走** | 圆环恢复交互（不做 0ms 可走——省急停补帧，视觉无差别；修订 ③：无 Enter 直触，键盘通道已移除） |
| 0.98s ~ | 扫读 | 按住 1.25s 打满（最迟 2.23s 走） |
| 退场 0~0.15s | **揭示** | 首行聚焦（青色辉光+其余条目压暗 50%+光标消失）‖ 点题句**琥珀通电**（全页唯一一次琥珀）‖ **标题字重通电**（可变字重 700→900，提案 A）——「首行被青光照亮+点题被琥珀照亮+标题变重」同一拍 = 被看见的揭示瞬间 |
| 0.15 ~ 0.30s | 黑场 | 全页 opacity→0（power2.in），留极弱星点 = 面板落点坐标 |
| 0.30s | **S1 面板落下** | 黑场结束帧 = 面板落下帧（硬切） |

**总账**：最慢 0.9+0.08+1.25+0.3 = **2.53s** 进 S1；最快 ≈1.28s。无单次动效超 800ms（最大单次 = 标题字符 0.35s）。

**报告条目筛选标准**（一刀）：揭短不表功 / 具体到有画面 / 零修辞冷着说（数据行零「你」字，冷热分明）。被看穿感排序：摩擦五类（王炸）> 满意度 > 多会话并行 > 会话时长 > 消息数/工具次数 > token（空洞之王，别占首屏）。

**特殊条目 = 首行**：「38% 的摩擦，同一个原因」——最像在说你，又最冷。高亮是放大器不是发电机，裸奔（无「它最在意」标签——AI 没有在意）。数值 2026-08-11 校准自主人真实月报（摩擦分布 24/63 ≈ 38%）；「卡壳」→「摩擦」对齐机制术语（facet）。

**语气 = 展签声**：钩子（俏皮）→ 条目（冷数据实锤）→ 点题句（收束）。全页「你」「它」各 5 个，全为真实指称；条目零「你」。

### 换行规则（2026-08-07 主人补充修正）

| 区块 | 换行策略 | 依据 |
|---|---|---|
| 钩子 | **`<br>` 强制两行**（「你每天指挥它干活。」/「今天轮到它点评你。」），禁宽度自然折行 | 反转节奏靠两行的停顿感；折行位置失控会破坏「俏皮→反转」的拍点（刺头：反转不可稀释） |
| 点题句 | 允许折两行，**折行后整体重心居中**（flex 居中容器） | 「报告是它写的，句句说的是你。」14 字 × 2.8rem ≈ 630px，已顶到 640px 容器极限；窄屏（<720px）必然两行，按两行设计而不是祈祷一行 |
| 报告条目 | **等宽字体禁止折行**——键值对一行装下；窄屏时容器优先缩小字号（0.78rem→0.7rem 档），再不行才允许容器横向滚动 | 数字行折行 = 数据被截断的观感（物证完整性） |
| 副题/三环节 | 允许自然折行 | 语义完整句，折行无损节奏 |

## 4. 视觉系统

**配色（四色角色）**：
- 黑场 `#05070d`：全程
- 冷蓝微光 `#3b6cf6` 系：手电筒，全程在场，揭示瞬间瞬亮一次
- 青紫晕 `#8b5cf6`：埋着的暗示，入场淡入后永不参与任何动效
- **琥珀 `#f5b942`：全页只出现一次**——揭示瞬间点题句通电光尾（100~150ms），出现次数=1 可自动核验

**字体（4 级）**：展签（标题 Playfair Display 700 斜体 6.5rem，暗态 40% 亮度）/ 悬念句（副题+钩子，思源宋体 Heavy 1.0-1.15rem）/ 点题句（思源宋体 900 1.6-2.8rem）/ 物证行（JetBrains Mono 等宽 0.78rem，条目+三环节+私有标记）。Playfair 只出现一次；语境字一律等宽。

**字体加载（Google Fonts，2026-08-07 主人补充修正 + 优化定稿）**——现状 `index.html` 已加载，字体栈与加载清单如下：

| 字体 | 字重 | 加载于 | 用途 |
|---|---|---|---|
| JetBrains Mono | 400 / 700 | index.html Google Fonts | --font-mono 等宽（条目/三环节/私有标记/圆环符号） |
| Noto Sans SC（思源黑体） | 400 / 500 / 700 / 900 | 同上 | --font-body 正文兜底 |
| Noto Serif SC（思源宋体） | 900 | 同上 | --font-serif（副题/钩子/点题句——900 已够，字号区分层级） |
| Playfair Display | **斜体可变 700~900** | 同上 | 标题 /insights（可变字重 = 「字重通电」动效的前提） |

**⚠️ 加载修正（实施必做）**：index.html 现加载 `Playfair+Display:ital,wght@1,900`——**需改为可变字重范围 `ital,wght@1,700..900`**，同时满足：① v2 规格标题起始 700（去宣告感）；② 提案 A「字重通电」需要在 700~900 之间做渐变。

**降级链（Google Fonts 加载失败时）**：Playfair → 'Times New Roman' → serif；思源宋体 → 'Songti SC' → 'SimSun' → serif；思源黑体 → 'PingFang SC' → 'Microsoft YaHei' → sans-serif；JetBrains Mono → ui-monospace → Consolas → monospace（现状 CSS 已具备，保持）。中文字体走 Google Fonts 的可用性依赖网络环境，fallback 全站已就位。

**私有标记行（已移除，2026-08-11 主人裁决）**：原 `-rw------- 1 you you · 0600（仅你可读）` 删除——ASCII 权限串对不懂的观众是噪声墙、对懂的观众是表演性装腔，两种观众都出戏；「仅你可读」的私密感由副题与点题句承载，防围观滑移职责并入合成数据声明（该声明亦按同日裁决移除，见 §7 覆盖记录）。原含义存档：Unix `ls -l` 权限输出，`0600` = 所有者可读写、组/其他人零权限，知识页附录 B 为机制来源。

**材质**：颗粒平时 0.02 冻结，揭示时 300ms 脉冲且**聚在点题句周围**；星点 20-30 颗 + 3-5 颗心跳星（1.5s 周期，将死未死的灯丝）；视差 ±6px 三层只碰背景；圆环青色 1px 呼吸 2s。

**字体优化定稿（2026-08-07 主人选 A+B+D，C 不选）**：

1. **提案 A · 标题「字重通电」**：揭示瞬间，标题除亮度 40%→75% 外，`font-variation-settings: 'wght'` 同步 700→900 渐变（与琥珀通电同拍，≤800ms）——「被看见的光有重量」：从暗而轻（还没通电的灯）到亮而重（被点亮的命令）。仅 Playfair 可变字体支持，中文无可变版本——这项动效由标题独占，恰与「字即图形」的定位一致。修订 ②：字号上限 6.5→7.5rem（与正文比值 ≈9.6:1）。
2. **提案 B · 钩子高亮（修订 ② 扩版）**：「今天轮到它**点评你**。」整组动词包 `<span class="hl-you">`，青色 + 加大（1.7rem）——蓝色与放大从「你」扩到「点评你」三字；色彩逻辑闭环：青色=关于你的数据（条目键/「点评你」/圆环/月球光晕）、琥珀=被看见的瞬间（点题）、冷蓝=环境光。
3. **提案 D · 条目数字 tabular-nums**：条目数字加 `font-variant-numeric: tabular-nums`——等宽数字对齐工整，物证像打印出来的。
4. **（C 不选）**：钩子保持思源宋体，不换黑体——声部分工维持原状。

**修订 ② · 星空与月球（2026-08-11）**：星点 20-30 → **160 颗**（~25% 为 3px 亮星，固定种子 LCG 可核验），心跳星 3-5 → **10 颗**；右上角新增 **WebGL 真球体月球**（`prologue.js createMoonMesh`：Three.js 网格 + 斜轴 23.4° 自转 60s/圈 + 左上光源，贴图本地化 `public/moon.jpg` 无网络依赖；序章全程要求 WebGL2，无降级路径）。

**修订 ② · 呼吸灯**：圆环底环常亮大喘气——底色 0.85 alpha，呼吸区间 **0.5→1.0**（有效亮度 0.43→0.85，沉而不灭、涨到全亮）；环心 `/insights` 与边框同参数同相位呼吸（core-breathe 0.55→1.0），80ms 真空同停。按住反馈：径向圆辉光（`::after` inset -20px，text-shadow 矩形辉光已移除——它会被渲染成方框）。

## 5. 交互（修订 ③：两条通道，键盘/降级已移除）

| 通道 | 怎么走 | 反馈 |
|---|---|---|
| 鼠标 | 悬停圆环（脉动增强）→ 按住 1.25s | 进度环匀速、按压微放大、松开回弹 |
| 触屏 | 长按 1.25s | 同上。**必须 `user-select: none`**（防 Android 长按弹系统菜单）+ `touch-action: none` |
